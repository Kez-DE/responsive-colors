# Responsive Colors — Basic Media Queries

A responsive website for the Basic Media Queries assignment.

- Mobile, below 772px: one column.
- Tablet, from 772px: two columns; divs are 45vw and images have a maximum height of 30vh.
- Large screens, from 998px: three columns; divs are 30vw.

Live website: https://kez-de.github.io/responsive-colors/

Open `index.html` in a browser. Resize the viewport to check each layout.
The two media queries are in `css/style.css`.

Run `python3 test-responsive.py` on macOS with Google Chrome installed to verify
375px, 771px, 772px, 997px, 998px, and 1440px layouts, loaded images, and overflow.

Based on the course starter: https://github.com/UMSIComplexWebDesign/ResponsiveHomeworks
The original page content, images, and mobile styles are retained.
